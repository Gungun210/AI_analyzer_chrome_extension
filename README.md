# 🤖 AI Analyzer – Chrome Extension

AI Analyzer is a powerful Chrome extension that helps you instantly analyze text, images, and web content using advanced AI. It provides quick insights, summaries, and smart suggestions directly in your browser, boosting productivity and saving time.

---

## 🚀 Features

- ✨ **Text Analysis** – Analyze selected text for meaning, tone, and key insights  
- 📄 **Summarization** – Generate short and clear summaries of long content  
- 🧠 **Smart Suggestions** – Get AI-powered recommendations and improvements  
- 🌐 **Webpage Analysis** – Extract insights from entire web pages  
- 🖼️ **Image Understanding (optional)** – Analyze image content  
- ⚡ **Fast & Lightweight** – Works instantly without slowing your browser  

---

## 🛠️ Installation

### Method 1: Load Unpacked Extension (Developer Mode)

1. Download or clone this repository  
2. Open **Google Chrome**  
3. Go to `chrome://extensions/`  
4. Enable **Developer Mode** (top right)  
5. Click **Load unpacked**  
6. Select the project folder

## ⚙️ How It Works

1. Select text on any webpage  
2. Click on the AI Analyzer extension icon  
3. Choose the type of analysis  
4. Get instant AI-generated results
